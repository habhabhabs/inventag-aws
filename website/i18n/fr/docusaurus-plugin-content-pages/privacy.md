# Confidentialité et cookies

Ce site se limite à l’essentiel. Rien d’optionnel ne s’exécute sans votre accord.

## Essentiels : toujours actifs

Ces éléments sont enregistrés dans le stockage local de votre navigateur, uniquement sur votre appareil. Ils ne sont envoyés nulle part.

| Nom | Ce qu’il mémorise | Durée |
|---|---|---|
| `inventag-analytics` | Votre choix concernant les cookies : `granted` ou `denied` | Jusqu’à ce que vous effaciez les données du navigateur |
| `theme` | L’apparence claire, sombre ou celle du système, si vous en avez choisi une | Jusqu’à ce que vous effaciez les données du navigateur |

Les polices sont hébergées sur ce site : lire une page n’envoie donc aucune requête à des services de polices.

## Mesure d’audience (uniquement si vous l’autorisez)

Si vous choisissez « Autoriser l’analyse », le site charge Google Analytics 4. Il collecte des statistiques de visite : quelles pages sont consultées, d’où viennent à peu près les visiteurs, et le type d’appareil et de navigateur. Les visites sont rattachées à un identifiant aléatoire stocké dans un cookie, et non à votre nom. Cela aide les mainteneurs à voir quelles pages sont utiles. Les fonctions publicitaires restent désactivées : le site refuse le consentement pour le stockage publicitaire, les données utilisateur à des fins publicitaires et la personnalisation des publicités.

| Cookie | Rôle | Durée |
|---|---|---|
| `_ga` | Distingue les pages vues d’un visiteur de celles d’un autre | Jusqu’à 2 ans |
| `_ga_<id>` | Garde la session en cours d’un seul tenant | Jusqu’à 2 ans |

La façon dont le fournisseur traite ces données est décrite dans sa [politique de confidentialité](https://policies.google.com/privacy) et dans [la manière dont il utilise les informations des sites qui utilisent ses services](https://policies.google.com/technologies/partner-sites).

Si vous choisissez « L’essentiel seulement », fermez la bannière ou l’ignorez simplement, aucun code d’analyse n’est chargé et aucun cookie d’analyse n’est déposé.

## Changer d’avis

Utilisez « Préférences en matière de cookies » en bas de n’importe quelle page. Si vous désactivez l’analyse, le site cesse aussitôt d’envoyer les visites et supprime les cookies `_ga`. Vous pouvez aussi effacer les données de ce site dans les paramètres de votre navigateur.

## Hébergement

Le site est hébergé sur GitHub Pages. GitHub peut consigner des informations techniques, comme les adresses IP, pour exploiter et protéger le service. Voir la [Déclaration de confidentialité de GitHub](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).

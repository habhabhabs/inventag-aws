# InvenTag 文件

InvenTag 是一款免費、開源（MIT）的 Python 命令列工具。
你讓它指向一個或多個 AWS 帳戶，它會列出找到的資源、檢查它們的標籤，
並把結果寫成 Excel 工作簿和 Word 文件，交給從不開啟 AWS 控制檯的人也能看懂。

我們把這份清單稱為**物料清單（BOM）**：你執行了什麼、執行在哪裡、
歸誰負責，以及標籤是否規範。

## 試一試 {/* #try-it */}

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install inventag-aws
inventag --template standard-bom --create-excel --account-regions us-east-1
```

InvenTag 發佈在 [PyPI](https://pypi.org/project/inventag-aws/) 上。若要從原始碼執行，
請參閱[安裝](./getting-started/installation.md)。

InvenTag 使用你目前的 AWS 憑證，並把工作簿寫入 `bom_output/`。
請為它使用唯讀身份：
[設定唯讀存取](./guides/read-only-access.md)。

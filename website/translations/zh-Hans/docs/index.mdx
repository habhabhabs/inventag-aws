# InvenTag 文档

InvenTag 是一款免费、开源（MIT）的 Python 命令行工具。
你让它指向一个或多个 AWS 账户，它会列出找到的资源、检查它们的标签，
并把结果写成 Excel 工作簿和 Word 文档，交给从不打开 AWS 控制台的人也能看懂。

我们把这份清单称为**物料清单（BOM）**：你运行了什么、运行在哪里、
归谁负责，以及标签是否规范。

## 试一试 {/* #try-it */}

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install inventag-aws
inventag --template standard-bom --create-excel --account-regions us-east-1
```

InvenTag 发布在 [PyPI](https://pypi.org/project/inventag-aws/) 上。若要从源码运行，
请参阅[安装](./getting-started/installation.md)。

InvenTag 使用你当前的 AWS 凭证，并把工作簿写入 `bom_output/`。
请为它使用只读身份：
[设置只读访问](./guides/read-only-access.md)。

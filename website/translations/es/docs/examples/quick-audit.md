# Ejemplo: auditoría rápida de una cuenta

**Objetivo:** un inventario legible de una cuenta, en Excel y Word, en unos
minutos.

**Necesitas:** credenciales de la cuenta, por ejemplo
`aws sso login --profile prod-readonly` y `export AWS_PROFILE=prod-readonly`.

## Plantilla {#template}

La plantilla de configuración integrada `single-account` analiza `us-east-1` y
escribe ambos archivos con el diseño `standard-bom`. Cópiala e indica tus
regiones:

```bash title="Terminal"
inventag templates init single-account --output .inventag/templates/audit.yaml
```

```yaml title=".inventag/templates/audit.yaml"
format_version: 1
kind: config
name: audit
description: Scan the account of your current credentials and write Excel and Word reports.
spec:
  regions: [us-east-1, eu-west-1]   # the regions you use
  outputs: [excel, word]
  output_directory: bom_output
  report_template: standard-bom
```

## Comando {#command}

```bash title="Terminal"
inventag templates validate audit
inventag --template audit
```

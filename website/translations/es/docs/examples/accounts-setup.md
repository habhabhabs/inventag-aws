# Ejemplo: inventariar todas las cuentas de una organización

**Objetivo:** un informe que cubra todas tus cuentas, con una columna Account
y una comprobación de etiquetas.

**Necesitas:**

- un rol con el mismo nombre (aquí `InvenTagReadOnly`) en cada cuenta, con una
  [política de solo lectura](../guides/read-only-access.md#with-an-iam-role-in-each-account);
- credenciales de una identidad que pueda asumir esos roles, por ejemplo en la
  cuenta de administración o en una cuenta de seguridad delegada.

## Plantilla {#template}

Lista tus cuentas:

```bash title="Terminal"
aws organizations list-accounts --query "Accounts[?Status=='ACTIVE'].[Id,Name]" --output text
```

Copia la plantilla integrada y pon en ella tus cuentas:

```bash title="Terminal"
inventag templates init org-multi-account --output .inventag/templates/our-org.yaml
```

```yaml title=".inventag/templates/our-org.yaml"
format_version: 1
kind: config
name: our-org
description: Every active account, read-only
spec:
  accounts:
    - account_id: "111111111111"
      account_name: Production
      role_arn: arn:aws:iam::111111111111:role/InvenTagReadOnly
    - account_id: "222222222222"
      account_name: Staging
      role_arn: arn:aws:iam::222222222222:role/InvenTagReadOnly
    - account_id: "333333333333"
      account_name: Shared services
      role_arn: arn:aws:iam::333333333333:role/InvenTagReadOnly
  regions: [us-east-1]
  outputs: [excel, word]
  report_template: standard-bom
  tag_policy: finops-cost-allocation
  max_concurrent_accounts: 4
```

## Comando {#command}

```bash title="Terminal"
inventag templates validate our-org
inventag --template our-org
```

## Salida {#output}

Mientras los ID de marcador de posición siguen ahí, `validate` te avisa:

```text title="Terminal"
WARNING ~/acme-infra/.inventag/templates/our-org.yaml: account IDs 111111111111, 222222222222, 333333333333 look like placeholders; replace them with your own
OK    ~/acme-infra/.inventag/templates/our-org.yaml (config 'our-org')
```

## Siguientes pasos {#next-steps}

- Si una cuenta falla, InvenTag registra el error, informa de las demás y aun
  así termina con el código 0, así que revisa el registro. La causa habitual es
  la política de confianza del rol.
- [Analizar varias cuentas](../guides/scan-multiple-accounts.md) explica las
  opciones de ajuste.

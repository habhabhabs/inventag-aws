# Documentación de InvenTag

InvenTag es una herramienta de línea de comandos gratuita y de código abierto (MIT) escrita en Python.
La apuntas a una o varias cuentas de AWS. Lista los recursos que encuentra,
revisa sus etiquetas y escribe el resultado en un libro de Excel y en un documento
de Word que puedes entregar a alguien que nunca abre la consola de AWS.

A esa lista la llamamos **lista de materiales (BOM)**: qué ejecutas, dónde se ejecuta,
quién es su responsable y cómo está etiquetado.

## Pruébalo {/* #try-it */}

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install inventag-aws
inventag --template standard-bom --create-excel --account-regions us-east-1
```

InvenTag está en [PyPI](https://pypi.org/project/inventag-aws/). Para ejecutarlo
desde el código fuente, consulta [Instalación](./getting-started/installation.md).

InvenTag usa tus credenciales de AWS actuales y escribe el libro en
`bom_output/`. Dale una identidad de solo lectura:
[Configurar el acceso de solo lectura](./guides/read-only-access.md).

# Documentation d’InvenTag

InvenTag est un outil en ligne de commande gratuit et open source (MIT), écrit en Python.
Vous le pointez vers un ou plusieurs comptes AWS. Il liste les ressources qu’il trouve,
vérifie leurs étiquettes et écrit le résultat dans un classeur Excel et un document
Word que vous pouvez remettre à quelqu’un qui n’ouvre jamais la console AWS.

Nous appelons cette liste une **nomenclature (BOM)** : ce que vous exploitez, où cela tourne,
qui en est responsable et comment c’est étiqueté.

## Essayez-le {/* #try-it */}

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install inventag-aws
inventag --template standard-bom --create-excel --account-regions us-east-1
```

InvenTag est disponible sur [PyPI](https://pypi.org/project/inventag-aws/). Pour l’exécuter
depuis les sources, voir [Installation](./getting-started/installation.md).

InvenTag utilise vos identifiants AWS actuels et écrit le classeur dans
`bom_output/`. Donnez-lui une identité en lecture seule :
[Configurer l’accès en lecture seule](./guides/read-only-access.md).

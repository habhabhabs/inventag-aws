# Exemple : audit rapide d’un compte

**Objectif :** un inventaire lisible d’un compte, en Excel et en Word, en quelques
minutes.

**Ce qu’il vous faut :** les identifiants du compte, par exemple
`aws sso login --profile prod-readonly` et `export AWS_PROFILE=prod-readonly`.

Non vérifié sur l’AWS CLI : les commandes de connexion de cette section.

## Modèle {#template}

Le modèle de configuration intégré `single-account` analyse `us-east-1` et écrit
les deux fichiers avec la mise en page `standard-bom`. Copiez-le et indiquez vos régions :

```bash title="Terminal"
inventag templates init single-account --output .inventag/templates/audit.yaml
```

```yaml title=".inventag/templates/audit.yaml"
format_version: 1
kind: config
name: audit
description: Scan the account of your current credentials and write Excel and Word reports.
spec:
  regions: [us-east-1, eu-west-1]   # the regions you use
  outputs: [excel, word]
  output_directory: bom_output
  report_template: standard-bom
```

## Commande {#command}

```bash title="Terminal"
inventag templates validate audit
inventag --template audit
```

## Étapes suivantes {#next-steps}

- Ajoutez un contrôle des étiquettes : `inventag --template audit --template security-baseline`.
- Les valeurs des champs qui contiennent souvent des secrets, comme les variables
  d’environnement Lambda, apparaissent sous la forme `***REDACTED***` dans les rapports.
- Lancez-le chaque semaine : [Exécuter InvenTag en CI/CD](../guides/run-in-ci.md).
